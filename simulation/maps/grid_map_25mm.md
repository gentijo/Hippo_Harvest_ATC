# 25 mm Grid Map

- Width: `2.5 m`
- Height: `2.5 m`
- Resolution: `0.025 m`
- Grid cells: `100 x 100`
- Occupancy: all free
- A and B are runtime waypoint markers, not occupied obstacles

## Cell Interpretation

- Cell `(0, 0)` is the southwest cell.
- Cell `(99, 99)` is the northeast cell.
- The reported robot location is the cell containing the robot center point.
